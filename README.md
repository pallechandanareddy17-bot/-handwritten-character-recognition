# Handwritten Character Recognition ✍️

## 📌 Project Overview

Handwritten Character Recognition is a Machine Learning/Deep Learning project that recognizes handwritten characters from images. A Convolutional Neural Network (CNN) is trained on handwritten character images and used to predict the character present in a new image.

## 🎯 Objective

The main objective of this project is to build an automated system that can identify handwritten characters accurately using Deep Learning techniques.

## 🛠️ Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Pillow
* Google Colab

## 🧠 Model Used

**Convolutional Neural Network (CNN)**

The CNN learns important visual features from handwritten character images and classifies them into their respective character categories.

## 🔄 Project Workflow

1. Collect the handwritten character dataset
2. Load and preprocess the images
3. Resize images into a standard size
4. Normalize pixel values
5. Split the dataset into training and testing data
6. Build the CNN model
7. Train the model
8. Evaluate model performance
9. Save the trained model
10. Test the model with a new handwritten character image

## 📊 Model Evaluation

The model can be evaluated using:

* Accuracy
* Loss
* Confusion Matrix
* Classification Report
